# WasabiRub 2027 — direction concept (secondary "B" site)

A standalone concept exploring the 2027 movement-brand direction for WasabiRub.
**Not the live store** (wasabirub.com is unchanged). Unreleased — set to `noindex`.

- Homepage, Shop, and three product pages share `css/site.css` + embedded Cooper Hewitt fonts.
- Lifestyle imagery is AI-generated (Higgsfield) for direction; product shots are real.
- Live **prototype panel** (bottom-right): toggle typeface / accent / hero / statement band / section numbers. Hide with `?proto=off`.
- Built from `build.py` (regenerates the HTML pages).
